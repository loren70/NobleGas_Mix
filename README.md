
#Binary gas mixture (Noble gas) calculator

- The code is executed from the main file named transportProperties.py, which depends on the collisionIntegrals.py and nobleGasProperties.csv files.

-  The correlation equations were obtained from:
  J. Kestin, K. Knierim, E. A. Mason, B. Najafi, S. T. Ro, and M. Waldman. Equilibrium and Transport Properties of the Noble Gases and Their Mixtures at Low Density. J. Phys.    Chem. Ref. Data, Vol. 13, No.1, 1984 (PDF file included in this repository)
